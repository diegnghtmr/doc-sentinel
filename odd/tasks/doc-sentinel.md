# doc-sentinel — feature document (ODD)

Parent meta-harness repo that pins third-party sub-harnesses by exact `main` SHA (git submodules) and orchestrates them in three modes: `clean`, `detect`, `update`.
Source of design truth: `PLAN.md` (13 Nov 2026). This document holds the specs, tasks and log; read it until `## Log` inclusive.

## Specs

- **S1 — Parent repo + pinned sub-harnesses.** User: "este proyecto es de repositorio y acabar de, pues estos subproyectos, que a su vez vamos a crear un supernamespace para solucionar esto". Implement PLAN §1, §4, §5.1: repo `doc-sentinel`, package `doc_sentinel`, `third_party/<id>` git submodules checked out at the exact SHAs of PLAN §5.1, `pins.lock.json` with `schema_version`, `branch_policy`, and per-pin `id,url,branch,sha,path,inspected_at`. No vendored code. Acceptance (PLAN Fase 0): "`git submodule status` muestra exactamente esos SHA; `doc-sentinel version` corre."
- **S2 — CLI.** PLAN §6 verbatim surface:
  ```
  doc-sentinel clean  <file> [--output PATH] [--json] [--report PATH]
  doc-sentinel detect <file> [--json] [--report PATH] [--allow-network]
  doc-sentinel update [--dry-run] [--only ID] [--json]
  doc-sentinel version
  ```
  Exit codes per PLAN §6 table (0/1/2 per mode). `clean` default output `<stem>.cleaned<suffix>`; aborts if destination exists unless `--force-output`, never onto the input.
- **S3 — clean mode.** PLAN §2.1 + principles 2, 6, 7, 9: only watermarks-remover CLI scripts (`inspect_file.py`, `clean_file.py`, `clean_text.py`); never `server.py` / `POST /clean` / `rewrite_text.py` / Layer B / `--in-place`. Original SHA-256 unchanged. C2PA removal/residual always logged. Report never written inside the document. Acceptance (Fase 2): "el fixture Unicode del smoke (U+202F + U+200B) se limpia sin cambiar letras visibles"; "el original conserva el mismo SHA-256".
- **S4 — detect mode.** PLAN §2.2, §7, §10, §11: read-only, offline by default (`HF_HUB_OFFLINE=1`, `TRANSFORMERS_OFFLINE=1`), adapters perlecta, hidden-text-detector, subtext-scan, chk_defaced (separate process only, AGPL), unicode-smuggling-guard, plus own channel extractor (filename, metadata, comments, alt, hyperlinks, embedded, form fields, tracked changes). Per L20 ("no usemos el modelo local"): the local Prompt Guard 2 model is **not used by default** — `prompt-guard` is removed from the default detect matrix and is only an explicit opt-in (`detect --prompt-guard`, never downloads). The linguistic layer is own deterministic glue `instruction-phrases` (ES+EN rules, no model, no network), justified by the demonstrated gap in L8 (subtext-scan `phrases: []` on the Spanish samples); it is mandatory for text-bearing formats. Severity: high when the matched text is hidden (revealed by a document-layer adapter) or sits in filename/metadata/comment/annotation/alt/hyperlink/embedded/form/tracked-change channels; medium when it is visible body text (a document may legitimately discuss prompt injection). Missing adapters appear in `adapters_skipped`; never pretend a layer ran.
- **S5 — Schema + deterministic aggregator.** PLAN §8, §9: normalized finding (`class`, `channel`, `severity` controlled vocabularies), run report JSON, severity mapping, dedup rule, verdicts `clean`/`findings`/`error` (detect) and `cleaned`/`already_clean`/`residual`/`error` (clean). "El agente no emite el veredicto." Aggregator calls no LLM.
- **S6 — Intent router.** PLAN §12 + Fase 1: rules-based, Spanish and English: «límpialo», «quita las marcas», *clean*; «revisa», «detecta injection», *detect* / *scan*; «actualiza», *update* / *bump pins*. Acceptance: "100 % de fixtures de intención bien clasificados".
- **S7 — update mode.** PLAN §5.2 algorithm: fetch, compare, checkout new, changelog `git log --format='%h %s' old..new` (max 30 lines), run corpus, persist or roll back **only** that pin; statuses `unchanged | updated | rolled_back | fetch_error`; `UPDATES.md` entry; exit 0/1/2. Acceptance (Fase 5): "un test de integración simula un pin roto ... y verifica el rollback de **solo** ese id; un pin bueno avanza y queda registrado."
- **S8 — Agent contracts.** `AGENTS.md` and `CLAUDE.md` with the content of PLAN §12 and §13.
- **S9 — Corpus.** PLAN §15: fixtures generated by script (no opaque binaries without recipe), `tests/corpus/manifest.yaml` with `must_find` / `must_not_find` / `visible_unchanged`; clean controls must not raise `high`/`critical`. Per L20, every corpus entry that skipped for lack of the model or for lack of a realistic fixture must be backed by a synthetic or publicly sourced example built the way the attack/trace really occurs (e.g. Word white 1 pt runs like the user's samples, the same converted to PDF, C2PA-signed media from public test fixtures fetched by pinned URL + SHA-256 into a git-ignored dir, PDFs with AI producer/XMP metadata, ToUnicode-remapped fonts, OCR-able injection images, Spanish metadata/filename injections), plus visible-discussion controls that must not raise high. Human-openable copies are also generated into `samples/synthetic/` (git-ignored) for manual experiments.
- **S10 — Experiments with the user's samples.** User: "También te puse los ejemplos ... tres documentos de Word. Dos son para la parte de inyección de prompt y la otra es para la parte de marca de agua. La idea es que experimentemos con estos para validar que funcione". `detect` on `ejemplo 1 prompt.docx` and `ejemplo 2 prompt.docx` must report the hidden AI-directed instructions (verdict `findings`); `clean` on `ejemplo 3 marca de agua.docx` must remove the AI-tool trace it carries into a new file and leave the original byte-identical. Per L6 the trace to remove is the HTML-paste residue: unreferenced `<w:div>` entries in `word/webSettings.xml` and orphan custom character styles whose names are CSS-class-like and that no part references (e.g. `o00408`, `s01997`, `first-table-reference`); visible text must stay identical. Implemented as own deterministic glue (`doc_sentinel/glue/ooxml_paste.py`) chained after watermarks-remover, justified by this sample as a demonstrated gap (PLAN principle 1). Per L10/L11, `clean` on the four new watermark samples must output copies whose post-clean inspect shows no AI metadata (creator/lastModifiedBy/description/Application/Company/custom AI props, library-default generator fingerprints such as docx-js `Un-named` and python-docx `generated by python-docx`), no C2PA in embedded media (or the residual is reported), and no invisible Unicode (U+200B/U+200D/U+202F), with visible text otherwise unchanged; originals byte-identical. Any trace WMR leaves behind is a demonstrated gap closed by own glue.
- **S11 — Containers + CI + README.** PLAN §3, §16, Fase 6: `containers/Dockerfile.detect`, `Dockerfile.clean`, `compose.yaml`; `.github/workflows/ci.yml`; README.
